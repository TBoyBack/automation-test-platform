## 1. 项目背景与目标

### 1.1 背景

创业公司测试团队现状分析：

| 维度 | 现状 |
|------|------|
| 团队规模 | 6人（2高级测试 + 4初级测试） |
| 业务覆盖 | 5条业务线 |
| 测试模式 | 人工测试为主 |
| 迭代频率 | 频繁迭代 |
| 团队状态 | 疲惫、工作量大 |

### 1.2 痛点分析

```
┌─────────────────────────────────────────────────────────────────┐
│                        当前痛点                                  │
├─────────────────────────────────────────────────────────────────┤
│  ❌ 每次迭代需回归 5条业务线，人力成本高                        │
│  ❌ 频繁迭代导致回归测试覆盖不足，质量风险累积                   │
│  ❌ 人工测试重复劳动，团队疲惫且效率低下                        │
│  ❌ 缺乏有效的测试过程记录，bug复现困难                         │
│  ❌ 设备碎片化（多款Android机型），兼容性测试难以保证           │
│  ❌ H5小游戏测试依赖人工验证，缺乏自动化手段                    │
└─────────────────────────────────────────────────────────────────┘
```

### 1.3 建设目标

| 阶段 | 目标 | 预期效果 |
|------|------|----------|
| 短期 | 核心业务流程自动化 | 减少50%回归人力 |
| 中期 | 全链路测试覆盖 | 测试覆盖率提升至80% |
| 长期 | AI智能化测试 | 降低测试维护成本 |

## 2. 技术选型分析

### 2.1 框架对比总览

| 维度 | Midscene.js | Appium2 + UIAutomator2 | Airtest |
|------|-------------|------------------------|---------|
| **定位方式** | AI视觉定位 | 元素属性定位 | 图像识别+坐标 |
| **学习成本** | 低（自然语言） | 中（需熟悉定位策略） | 中（图像脚本） |
| **维护成本** | 低（AI自适应） | 高（UI变化需更新定位） | 中（图像需更新） |
| **WebView支持** | ⚠️ 需结合Playwright | ✅ 原生支持 | ⚠️ 有限 |
| **H5小游戏** | ⚠️ 视觉方案可行 | ⚠️ 需Web测试框架 | ✅ 图像识别适配 |
| **视频录制** | 内置可视化报告 | 需插件 | ✅ 内置录屏 |
| **开源活跃度** | 活跃（11k+ GitHub stars） | 非常活跃 | 活跃 |
| **社区生态** | 快速增长 | 成熟庞大 | 成熟 |

### 2.2 Midscene.js 深度分析

**核心优势：**

```
┌────────────────────────────────────────────────────────────┐
│                  Midscene.js 核心能力                       │
├────────────────────────────────────────────────────────────┤
│  ✅ 自然语言交互：用自然语言描述操作意图，AI自动规划执行     │
│  ✅ 视觉驱动定位：不依赖DOM/XPath，UI变化自适应             │
│  ✅ 降低门槛：非技术人员也能编写测试用例                     │
│  ✅ 可视化报告：每步操作截图+AI推理结果+Token消耗           │
│  ✅ 跨平台：Web/PC/Android/iOS/车机大屏                      │
│  ✅ 开源免费：MIT协议，支持私有化部署                       │
│  ✅ Token节省：视觉方案减少80% token消耗                    │
└────────────────────────────────────────────────────────────┘
```

**API能力：**

```javascript
// 视觉点击
await agent.aiTap('页面右上角的用户头像');

// 视觉输入
await agent.aiInput('搜索框', { value: '关键词' });

// 视觉断言
await agent.aiAssert('页面显示了成功提示');

// 数据提取
const count = await agent.aiQuery('{ count: number }', '任务总数');

// 合并多步操作（省Token）
await agent.aiAction('填写用户名，点击登录按钮');
```

**适用场景：**
- ✅ Web端H5测试（结合Playwright）
- ✅ Android/iOS APP测试
- ⚠️ 混合APP WebView部分（需切换上下文）
- ⚠️ H5小游戏（依赖游戏提供SDK或使用图像识别回退）

#### 4.3.2 核心表结构

```sql
-- 项目表
CREATE TABLE project (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
```

```python
from appium import webdriver

from appium.options.common import AppiumOptions

class AppiumEngine:
    def __init__(self, device_config):

        self.capabilities.platform_name = "Android"

        self.capabilities.udid = device_config['udid']
        self.capabilities.app_package = device_config['app_package']

        self.driver = None

        """建立设备连接"""
        self.driver = webdriver.Remote(
            "http://localhost:4723",
            options=self.capabilities
        )
        return self.driver
    
    def switch_to_webview(self):
        """切换到WebView上下文"""
        contexts = self.driver.contexts
        print(f"可用上下文: {contexts}")
        # 切换到最后一个WebView
        for ctx in contexts:
            if ctx.startswith('WEBVIEW'):
                self.driver.switch_to.context(ctx)
                return ctx
        raise Exception("未找到WebView上下文")
    
    def switch_to_native(self):
        """切换回Native上下文"""
        self.driver.switch_to.context('NATIVE_APP')
    
    def execute_steps(self, steps):
        """执行测试步骤"""
        results = []
        for step in steps:
            action = step['action']
            if action == 'tap':
                self.driver.tap([(step['x'], step['y'])])
            elif action == 'input':
                self.driver.find_element(*step['locator']).send_keys(step['value'])
            elif action == 'click':
                self.driver.find_element(*step['locator']).click()
            elif action == 'screenshot':
                self.driver.save_screenshot(step['path'])
            results.append({'status': 'success', 'step': step})
        return results
    
    def quit(self):
        """断开连接"""
```

### 5.3 Midscene.js执行引擎（H5/Web）

```javascript
// midscene_engine.js
import { PlaywrightAgent } from '@midscene/web/playwright';
import { chromium } from 'playwright';
import 'dotenv/config';

class MidsceneEngine {
  constructor(config) {
    this.browser = null;
    this.context = null;
    this.page = null;
    this.agent = null;
    this.config = config;
  }

  async initialize() {
    // 启动浏览器
    this.browser = await chromium.launch({
      headless: this.config.headless ?? false
    });
    
    // 创建上下文和页面
    this.context = await this.browser.newContext({
      viewport: this.config.viewport ?? { width: 1280, height: 720 }
    });
    this.page = await this.context.newPage();
    
    // 初始化Midscene Agent
    this.agent = new PlaywrightAgent(this.page);
  }

  async executeSteps(steps) {
    const results = [];
    
    for (const step of steps) {
      try {
        const action = step.action;
        let result;
        
        switch (action) {
          case 'navigate':
            await this.page.goto(step.url);
            result = { status: 'success', message: `导航到 ${step.url}` };
            break;
            
          case 'aiTap':
            await this.agent.aiTap(step.prompt);
            result = { status: 'success', message: `点击: ${step.prompt}` };
            break;
            
          case 'aiInput':
            await this.agent.aiInput(step.prompt, { value: step.value });
            result = { status: 'success', message: `输入: ${step.value} 到 ${step.prompt}` };
            break;
            
          case 'aiAssert':
            await this.agent.aiAssert(step.prompt);
            result = { status: 'success', message: `断言: ${step.prompt}` };
            break;
            
          case 'aiQuery':
            result = await this.agent.aiQuery(step.schema, step.prompt);
            result = { status: 'success', message: `查询: ${step.prompt}`, data: result };
            break;
            
          case 'screenshot':
            await this.page.screenshot({ path: step.path });
            result = { status: 'success', message: `截图保存至 ${step.path}` };
            break;
        }
        
        // 记录截图到报告
        await this.agent.recordToReport(`Step: ${action}`);
        
        results.push(result);
      } catch (error) {
        results.push({
          status: 'error',
          message: error.message
        });
        await this.page.screenshot({ path: `error_${Date.now()}.png` });
      }
    }
    
    return results;
  }

  async terminate() {
    if (this.browser) {
      await this.browser.close();
    }
  }
}

export default MidsceneEngine;
```

### 5.4 设备调度策略

```python
# device_scheduler.py
from dataclasses import dataclass
from typing import List, Optional
from enum import Enum

class DeviceStatus(Enum):
    ONLINE = "online"
    BUSY = "busy"
    OFFLINE = "offline"

@dataclass
class Device:
    id: int
    name: str
    udid: str
    device_type: str
    os_version: str
    status: DeviceStatus = DeviceStatus.OFFLINE
    current_task: Optional[str] = None

class DeviceScheduler:
    def __init__(self):
        self.devices: List[Device] = []
    
    def register_device(self, device: Device):
        """注册设备"""
        device.status = DeviceStatus.ONLINE
        self.devices.append(device)
    
    def unregister_device(self, device_id: int):
        """注销设备"""
        for device in self.devices:
            if device.id == device_id:
                device.status = DeviceStatus.OFFLINE
    
    def allocate_device(self, device_type: str = None, os_version: str = None) -> Optional[Device]:
        """分配可用设备"""
        available = [
            d for d in self.devices 
            if d.status == DeviceStatus.ONLINE
            and (device_type is None or d.device_type == device_type)
            and (os_version is None or d.os_version == os_version)
        ]
        
        if not available:
            return None
        
        # 优先选择任务最少的设备（负载均衡）
        selected = min(available, key=lambda d: d.current_task or "")
        selected.status = DeviceStatus.BUSY
        return selected
    
    def release_device(self, device_id: int):
        """释放设备"""
        for device in self.devices:
            if device.id == device_id:
                device.status = DeviceStatus.ONLINE
                device.current_task = None
```

```python
# screen_recorder.py
import subprocess
import os
import time
from pathlib import Path

class ScreenRecorder:
    def __init__(self, device_udid: str, output_dir: str):
        self.device_udid = device_udid
        self.output_dir = Path(output_dir)
        self.recording = False
        self.process = None
        self.output_file = None
    
    def start_recording(self, max_time: int = 600, fps: int = 15):
        """开始录屏
        
        Args:
            max_time: 最大录制时长（秒）
            fps: 帧率
        """
        if self.recording:
            raise Exception("已经在录制中")
        
        # 创建输出目录
        self.output_dir.mkdir(parents=True, exist_ok=True)
        
        # 生成文件名
        timestamp = time.strftime("%Y%m%d_%H%M%S")
        self.output_file = self.output_dir / f"recording_{self.device_udid}_{timestamp}.mp4"
        
        # ADB录屏命令
        # 注意：screenrecord需要API 19+，默认限制10分钟
        cmd = [
            "adb", "-s", self.device_udid,
            "shell", "screenrecord",
            f"--time-limit={min(max_time, 600)}",
            f"--bit-rate={fps * 1024 * 1024}",  # 15Mbps
            f"/sdcard/screen_{timestamp}.mp4"
        ]
        
        # 在后台启动录制
        self.process = subprocess.Popen(cmd)
        self.recording = True
        
        print(f"开始录屏: {self.output_file}")
        return self.output_file
    
    def stop_recording(self):
        """停止录屏并保存"""
        if not self.recording:
            return None
        
        # 终止录制进程
        if self.process:
            self.process.terminate()
            self.process.wait(timeout=5)
        
        # 从设备拉取视频
        # 查找最新的录屏文件
        timestamp = time.strftime("%Y%m%d_%H%M%S")
        remote_file = f"/sdcard/screen_*.mp4"
        
        pull_cmd = [
            "adb", "-s", self.device_udid,
            "pull",
            remote_file,
            str(self.output_dir)
        ]
        
        try:
            subprocess.run(pull_cmd, check=True, timeout=30)
        except subprocess.CalledProcessError:
            print("警告：无法从设备拉取视频文件")
        
        # 清理远程文件
        subprocess.run([
            "adb", "-s", self.device_udid,
            "shell", "rm", "-f", "/sdcard/screen_*.mp4"
        ])
        
        self.recording = False
        print(f"录屏完成: {self.output_file}")
        return self.output_file
    
    def __enter__(self):
        self.start_recording()
        return self
    
    def __exit__(self, exc_type, exc_val, exc_tb):
        self.stop_recording()
```
