## 1. 项目概述

### 1.1 项目定位

**自动化测试平台**是一站式移动端 & Web 自动化测试平台，为创业公司测试团队打造的自动化测试能力建设解决方案。

### 1.2 支持场景

| 测试类型 | 技术方案 | 适用场景 |
|---------|---------|---------|
| **Android Native** | Appium2 + UIAutomator2 | 原生 Android 应用 UI 自动化 |
| **Android WebView** | Appium2 + Chromedriver | 混合应用中 H5 页面的自动化测试 |
| **H5 Web 应用** | Midscene.js + Playwright | 纯 Web 应用的 AI 驱动测试 |
| **H5 游戏** | Airtest + 图像识别 | 游戏类应用的图像匹配测试 |

### 1.3 核心特性

- 🤖 **AI 驱动**：集成 Midscene.js，支持自然语言编写测试用例
- 📱 **跨平台**：支持 Android Native、WebView、H5 游戏
- 🎥 **视频回放**：FFmpeg 录屏，完整复现测试过程
- ⚡ **高效执行**：分布式任务调度，支持并发执行
- 📊 **可视化报告**：Allure 报告 + 自定义 HTML 报告

## 4. 核心模块详解

### 4.1 Appium 引擎 (hybrid_app_test.py)

**模块职责**：实现 Android 混合 APP 的自动化测试，支持 Native 和 WebView 之间的上下文切换。

**核心类**：`HybridAppTest`

```python
class HybridAppTest:
    """混合 APP 测试基类"""
    
    属性:
        - config: Dict[str, Any]      # 设备配置
        - driver: webdriver.Remote    # Appium WebDriver
        - current_context: str        # 当前上下文
    
    方法:
        - __init__(config)            # 初始化测试
        - setup()                      # 建立 Appium 连接
        - switch_to_webview()          # 切换到 WebView 上下文
        - switch_to_native()           # 切换回 Native 上下文
        - get_all_contexts()           # 获取所有上下文
        
        # Native 操作
        - native_click(by, value)      # Native 点击
        - native_input(by, value, text) # Native 输入
        - native_screenshot(path)      # 截图
        
        # WebView 操作
        - webview_click(selector, type) # WebView 点击
        - webview_input(selector, text) # WebView 输入
        - webview_execute_script()      # 执行 JavaScript
        
        - teardown()                   # 断开连接
```

**子类**：`ExampleHybridTest` - 提供完整测试流程示例

### 4.2 Midscene 引擎 (midscene/)

#### 4.2.1 配置模块 (config.ts)

**配置分类**：

| 配置项 | 说明 |
|-------|------|
| `modelConfig` | AI 模型配置（API 地址、密钥、模型名称） |
| `visionModelConfig` | 视觉模型配置（温度、token 上限） |
| `reportConfig` | 报告配置（输出目录、报告类型） |
| `executionConfig` | 执行配置（超时设置） |
| `browserConfig` | 浏览器配置（视口、User-Agent） |
| `deviceConfig` | 设备配置（Android、WebView） |

#### 4.2.2 H5 游戏测试基类 (h5_game_test.ts)

**核心类**：`MidsceneGameTest`

```typescript
class MidsceneGameTest {
    属性:
        - browser: Browser              # Playwright 浏览器实例
        - context: BrowserContext       # 浏览器上下文
        - page: Page                    # 页面实例
        - agent: PlaywrightAgent        # Midscene Agent
        - config: TestConfig            # 测试配置
    
    方法:
        - setup()                       # 初始化浏览器
        - executeStep(step)            # 执行单个测试步骤
        - runTest(steps)                # 执行测试场景
        - teardown()                    # 清理环境
}
```

**支持的测试步骤类型**：

| 动作 | 说明 | 参数 |
|-----|------|------|
| `navigate` | 页面导航 | `url` |
| `aiTap` | AI 点击 | `prompt`（自然语言描述） |
| `aiInput` | AI 输入 | `prompt`, `value` |
| `aiAssert` | AI 断言 | `prompt` |
| `aiQuery` | AI 查询 | `prompt`, `schema` |
| `aiWaitFor` | AI 等待 | `prompt` |
| `screenshot` | 截图 | `path` |

**子类**：`H5GameTest` - H5 小游戏测试示例

#### 4.2.3 Web 测试示例 (web_test.spec.ts)

使用 Playwright Test 框架编写的集成测试示例：

- **测试用例 1**：`电商网站 - 搜索并筛选商品`
- **测试用例 2**：`社交媒体 - 发布图文帖子`
- **测试用例 3**：`表单网站 - 用户注册流程`

### 4.3 API 路由 (cases.js)

Express.js 路由处理器，提供用例管理的 RESTful API：

```javascript
// 路由端点

GET  /cases/:id       # 获取用例详情
POST /cases           # 创建用例
PUT  /cases/:id       # 更新用例
DELETE /cases/:id     # 删除用例
```

## 8. 数据库设计

### 8.1 核心表结构

```sql
-- 项目表
CREATE TABLE project (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL UNIQUE,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 测试套件表
CREATE TABLE test_suite (
    id SERIAL PRIMARY KEY,
    project_id INTEGER REFERENCES project(id) ON DELETE CASCADE,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    engine_type VARCHAR(20) DEFAULT 'appium',  -- 'appium', 'midscene', 'airtest'
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 测试用例表
CREATE TABLE test_case (
    id SERIAL PRIMARY KEY,
    suite_id INTEGER REFERENCES test_suite(id) ON DELETE CASCADE,
    name VARCHAR(200) NOT NULL,
    description TEXT,
    type VARCHAR(20) NOT NULL,  -- 'native', 'webview', 'h5'
    content JSONB NOT NULL,      -- 用例内容 (步骤、断言等)
    created_by VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 设备表
CREATE TABLE device (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    type VARCHAR(20) NOT NULL,           -- 'android', 'ios', 'browser'
    manufacturer VARCHAR(50),
    model VARCHAR(50),
    os_version VARCHAR(20),
    status VARCHAR(20) DEFAULT 'offline', -- 'online', 'offline', 'busy'
    last_used_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 测试任务表
CREATE TABLE test_task (
    id SERIAL PRIMARY KEY,
    case_id INTEGER REFERENCES test_case(id) ON DELETE CASCADE,
    device_id INTEGER REFERENCES device(id),
    status VARCHAR(20) DEFAULT 'pending',  -- 'pending', 'running', 'passed', 'failed'
    result JSONB,                           -- 执行结果详情
    video_url VARCHAR(500),                 -- 视频回放地址
    started_at TIMESTAMP,
    completed_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
